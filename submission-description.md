# Submission Description: CareerForge AI

CareerForge AI helps students turn vague career goals into actionable weekly plans.

A student selects a target role, shares their current skills, strengths, weak areas, and weekly time budget. The app generates a concise, role-specific package:
- Personalized roadmap
- Top skills to learn
- Portfolio project ideas
- Resume improvement checklist
- Interview question set
- Skill-gap analysis
- Weekly execution plan

What makes this strong for hackathon judging:
1. Clear problem and target user (students)
2. Immediate practical value
3. Fast time-to-understand during demo
4. Reliable functionality with AI + fallback mode
5. Clean, presentation-friendly dashboard
